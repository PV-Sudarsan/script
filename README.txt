COMPUTER NETWORKS LAB - PYTHON PROGRAMS
=======================================
Requirement: Python 3 (no extra packages, except Ex05 needs: pip install scapy)

Single-file programs (Ex01, Ex02, Ex05, Ex07, Ex08, Ex09a, Ex09b, Ex10):
    python <file>.py

Client/Server programs (Ex03a, Ex03b, Ex04, Ex06a, Ex06b):
    1. Open terminal 1 and run the server file:   python exXX_..._server.py
    2. Open terminal 2 and run the client file:   python exXX_..._client.py

Notes:
 - Ex02 needs internet access (downloads example.com into Download.html).
 - Ex05 must be run as Administrator / sudo.
 - Type "end" to stop the echo and chat programs.
 - Stop the DNS / ARP / RARP servers with Ctrl+C.
